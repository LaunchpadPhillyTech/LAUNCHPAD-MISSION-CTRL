# Coding & Project Instructions for LAUNCHPAD-MISSION-CTRL

## Naming Conventions
- Use kebab-case for page files (e.g., `page.tsx`) and PascalCase for React components (e.g., `AddPartnerForm.tsx`).
- Context providers and hooks use PascalCase and camelCase respectively (e.g., `AuthContext.tsx`, `useAIEmailGeneration.ts`).
- API route files use lowercase and descriptive names.

## Formatting
- Use Prettier for code formatting. Enforce 2-space indentation, single quotes, and trailing commas where valid.
- Use Tailwind CSS for styling, with shadcn/ui components for UI consistency.
- TypeScript strict mode must be enabled.

## Configuration
- All configuration files (e.g., `tsconfig.json`, `tailwind.config.js`, `postcss.config.mjs`) must be at the project root.
- Use the `@/*` alias for imports as configured in TypeScript.

## Dependencies
- Use npm for dependency management. All dependencies must be listed in `package.json`.
- Keep dependencies up to date and remove unused packages regularly.
- Use Prisma for database schema and migrations.
